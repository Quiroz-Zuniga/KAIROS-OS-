# 23. Geometría Kairós

> Documento de planificación o revisión previa. El [manual técnico actual](guia/arquitectura.md) describe el código disponible; las capacidades Linux de esta especificación siguen propuestas.


La guía normativa es [KAIROS_GEOMETRY](KAIROS_GEOMETRY.md). Aplica a escritorio, aplicaciones propias, tema Openbox, boot y material visual. Los valores son decisiones de diseño propuestas, pendientes de verificación visual con fuentes reales; no describen el CSS heredado.

El reconocimiento debe venir de retícula, bordes y jerarquía, además del logo. No clonar layouts de otros sistemas ni llenar la interfaz de búhos. Ambos temas comparten estructura. [22](22-color-system.md) define los tokens que materializan esta guía.
